## 如何替换问卷

> 📋 完整流程参见 [`操作流程/07-更换问卷流程.md`](操作流程/07-更换问卷流程.md)

如需替换某个测验，只需修改对应的 `01-`/`02-`/`03-` 文件，然后同步更新：

1. **前端问卷 JSON**：`src/data/questionnaires/lzu-*.json`
2. **计分引擎**：`server/services/lzuScoringService.js`
3. **AI Prompt**：`server/services/lzuReportGenerator.js`（如影响报告分析维度）
4. **报告模板**：`server/services/lzuReportTemplate.js`（如影响报告展示模块）
5. **DOCX 模板**：`server/services/lzuDocxBuilder.js`

## 如何修改综合报告

> 📋 完整流程参见 [`操作流程/08-修改综合报告流程.md`](操作流程/08-修改综合报告流程.md)，涵盖 5 大场景：
> - A. 修改计分规则（权重/公式/等级）
> - B. 调整 AI 分析内容（角度/深度/段落）
> - C. 修改报告结构（模块顺序/增删区域）
> - D. 修改报告样式（CSS/图表/布局）
> - E. 修改提示词参考文件
